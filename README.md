# Calculator Web App

This project is a simple calculator web application built for a university homework assignment. It provides users with a clean and user-friendly interface for performing basic arithmetic operations. The web app was developed using HTML, CSS, and JavaScript, with the help of a modern vibe coding tool, **Cursor**.

---

## Features

- **Basic Arithmetic Operations**  
  Perform addition, subtraction, multiplication, and division.

- **Keyboard Support**  
  Use your keyboard to enter numbers and operators, in addition to on-screen buttons.

- **Responsive Design**  
  Works on both desktop and mobile devices.

- **Clear Button**  
  Easily reset the calculator to its initial state.

- **Error Handling**  
  Displays an error for division by zero.

---

## Technologies Used

- **HTML** – Page structure
- **CSS** – Styling and layout
- **JavaScript** – Calculator logic and interactivity

**Vibe Coding Tool:**  
- [Cursor](https://www.cursor.so/)

## Installation and Setup

1. **Clone or Download the Repository**  
   - Click "Code" and choose "Download ZIP", or clone with  
     ```
     git clone <repository_url>
     ```

2. **Navigate to the Project Folder**  
   ```
   cd path/to/project-folder
   ```

3. **No Dependencies Required**  
   There’s no need to install any packages. All files are self-contained.

---

## How to Run the Project

1. **Open the Project Folder**
2. **Double-click `index.html`**  
   or  
   **Right-click and choose "Open with"** > your preferred browser.

That’s it! The Calculator web app should load and be ready for use.
