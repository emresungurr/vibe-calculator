# Experience Report: Building a Calculator Web Application with Cursor

## 1. Tool Selection Justification

During my university homework assignment to build a calculator web application, I chose Cursor as my primary coding tool. I was initially drawn to Cursor because it strongly emphasizes integrating AI support directly within the coding environment. Unlike traditional code editors, Cursor offers features such as in-line AI code suggestions, one-click documentation generation, and powerful search. For a student like me, who is aiming to become more efficient and confident with modern development workflows, this seemed very promising.

Another factor in my tool selection was the real-time feedback and seamless interactions that Cursor provides. Debugging and refactoring are common pain points for beginners, and Cursor’s AI-driven functionalities promised both guidance and explanation without having to switch between applications or search external resources. Since my project used the standard stack—HTML, CSS, and JavaScript—I felt that Cursor would provide a good balance between familiar coding patterns and helpful automation, without limiting my understanding of the actual code.

## 2. Development Process

I began by outlining the features I wanted for my calculator: basic arithmetic operations (addition, subtraction, multiplication, division), a visually clear and responsive UI, keyboard support, and error handling. With this checklist, I opened Cursor and set up my project files: `index.html`, `style.css`, and `script.js`. Right from the start, I noticed Cursor’s auto-completion and code summarization streamlined my workflow. For example, the AI assistant suggested accessible HTML markup and instantly highlighted missing button attributes or misplaced tags.

When moving to the CSS, I experimented with gradients and modern styling to give the app a clean look. Cursor’s instant preview and live feedback helped iterate my designs rapidly. The AI chat in Cursor also provided suggestions for improving accessibility—such as higher-contrast buttons—which I might have overlooked otherwise.

The JavaScript portion was the most involved. Cursor’s AI suggestions and inline docs were invaluable for structuring functions like input handling and operator chaining. Occasionally, I’d ask the AI how to best manage floating-point input or prevent multiple decimals. Cursor often included small code snippets or useful explanation boxes right where I needed clarification, which made me more confident in my implementation choices.

## 3. Challenges and Solutions

One of the main challenges I encountered was handling edge cases, specifically input validation and error states. For example, allowing multiple decimal points or dividing by zero could easily break the calculator’s logic. I spent a considerable amount of time debugging these issues.

Cursor’s AI chat helped break down complex issues into smaller steps. When I got stuck with the handling of chaining operations—like pressing multiple operators in a row—the AI would suggest logic or prompt me to add specific conditionals. I also made use of Cursor’s ability to highlight code that could be optimized or refactored. For instance, initially my clear/reset function left some internal state variables unchanged, but the AI hint reminded me to reset all of them consistently.

Responsive design was another challenge. I wanted the calculator to look good on both desktop and mobile devices. Cursor’s instant visual preview let me see the effects of CSS edits in real time. Sometimes the AI would even point out CSS properties or shorthand notations to make my styling cleaner.

## 4. Reflection

Using Cursor for this homework project made development both faster and more educational. Instead of simply searching for answers online, I could receive just-in-time explanations, which deepened my foundational knowledge, especially in JavaScript event handling and DOM manipulation. Having a built-in assistant gave me the confidence to experiment and refactor without the fear of completely breaking my project.

Looking back, I believe Cursor helped me bridge the gap between theory and practice. While the AI features occasionally offered solutions too quickly—which could be a temptation to accept without full understanding—I consciously chose to ask for explanations or to implement the suggestions manually to reinforce my learning.

Overall, I’m satisfied with both my learning process and the final result of my calculator web app. I would recommend Cursor to other students, especially those interested in leveraging modern, AI-enhanced workflows for practical web development assignments. The tool made the experience less intimidating, fostered curiosity, and empowered me to produce a functional, well-designed application within a short time frame.
